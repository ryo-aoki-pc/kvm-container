# qemu-kvm コンテナの文書索引

全体の概要と各シナリオの頻度は [リポジトリの README](../README.md) を参照する。初めて使う場合は、導入する → VM を作る → VM を使う の順に進める。

## 導入・VM の操作

手順書は [setup.md](setup.md) の 1 本。必要なシナリオ・節を次の表から選ぶ。

| 目的 | 手順 |
| --- | --- |
| ホストに導入する | [導入する (1 度だけ)](setup.md#導入する-1-度だけ) |
| VM を作成する | [VM を作る (VM ごとに 1 度)](setup.md#vm-を作る-vm-ごとに-1-度) |
| VM を起動・表示・停止する | [VM を使う (繰り返し)](setup.md#vm-を使う-繰り返し) |
| ホストの再ログイン後に画面を使う | [再ログインしたとき (繰り返し)](setup.md#再ログインしたとき-繰り返し) |
| VM をホストと同じネットワークにつなぐ | [VM をホストのブリッジにつなぐ (任意)](setup.md#vm-をホストのブリッジにつなぐ-任意) |
| VM の定義・UEFI 変数・ディスクを削除する | [VM を削除する](setup.md#vm-を削除する) |
| リポジトリとイメージを更新する | [更新](setup.md#更新) |
| 任意の節を戻す・導入したものを削除する | [ロールバック](setup.md#ロールバック) |
